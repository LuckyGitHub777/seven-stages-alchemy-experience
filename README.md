# Seven Stages of Alchemy — Interactive Experience

**Explore online:** [Open the public interactive website](https://luckygithub777.github.io/seven-stages-alchemy-experience/). Open the hosted browser experience first; the repository retains source code and optional local usage.

An interactive reflective journey through seven symbolic stages: **Calcination, Dissolution, Separation, Conjunction, Fermentation, Distillation, and Coagulation**.

Open [index.html](index.html) in a modern browser. Enter a real question or project and work through the stages. Review your own reflections before acting; controls are designed to keep progression deliberate and reversible.

The stages are a **symbolic framework for reflection**, not a medical intervention, historical reconstruction, proof of an alchemical mechanism, or prediction of outcomes. No account, cloud model or hosted backend is required.
